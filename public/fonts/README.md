Legacy font families self-hosted from the official Google Fonts repository on 2026-10-17, with the accompanying OFL licenses.

- Rubik variable: https://github.com/google/fonts/tree/main/ofl/rubik
- Courier Prime normal, bold, italic and bold italic: https://github.com/google/fonts/tree/main/ofl/courierprime

This retains the existing families on deep course/legacy content while avoiding the failing Next Google-font loader. The approved public presentation uses the licensed Archivo and IBM Plex Mono files under /brand/fonts/.
